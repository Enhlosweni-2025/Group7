# The Eloquent Ear

The Eloquent Ear is a public-speaking training portfolio site for founders, entrepreneurs, and startup teams. The live site is available at **[theeloquentear.netlify.app](https://theeloquentear.netlify.app/)**.

## Selected projects

1. **[Amigo: Life’s Better With a Laugh](https://partyrock.aws/u/Noluthando123/RbzQM9bd8/Amigo%253A-Life%27s-Better-With-a-Laugh)** — an AWS PartyRock generative-AI project.
2. **[The Eloquent Ear / Group7](https://github.com/Enhlosweni-2025/Group7)** — this public-speaking training site. The repository history shows Noluthando Buda contributing the site pages, styling, JavaScript interactions, and media, alongside earlier contributions from Hope.
3. **[Introduction to OOP in Python](https://github.com/Aur-09/Introduction-to-OOP-in-Python)** — an AWS AI Programmer Scholar learning repository focused on Python object-oriented programming and related exercises.
4. **[Kovsie's Study and Assignment Tracker](https://github.com/Aur-09/ITSA-Hackathon-1st-Team-11)** — a C#/.NET Windows Forms assignment tracker for modules, deadlines, progress, and study scheduling, developed by Team 11.

The AWS Image Classification repository associated with the earlier challenge link was verified as `Aur-09/Image_classification_project`, but it is currently empty, so it is not presented as a completed portfolio project here.

## Run locally

This is a static site. Open `index.html` in a browser, or serve the repository directory with any static web server.
